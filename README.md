## ✨ 它能干啥

- **喊名就接话** —— 群里喊一声「咪咪」，它就顺着上文聊，不是复读模板
- **长期记忆，专翻旧账** —— 谁立过什么 flag、谁有什么梗，它都记得，时不时翻出来，全群笑点来源
- **联网吃瓜，分实锤和网传** —— 问它热点，它先分清哪些是实锤、哪些只是网传，不跟着瞎传
- **组局摇人** —— 喊组局时帮你点名、记人数，还记着谁上次放了鸽子
- **新人欢迎** —— 有人进群它先迎上去介绍群里的玩法，新人不潜水

## ❓ 常见问题

**Q：它聊起来像真人吗？**
A：它能顺着群里的上文接话、接梗，偶尔还会损人两句。到底像不像，看官网演示最直观——演示就是它在群里聊天的样子。

**Q：它真的记得住以前的事？**
A：记得住。群里谁说过什么、立过什么 flag、欠过谁奶茶，它都会在合适的时候翻出来。这也是用过的群里笑点最密的一项。

**Q：开通后用不了、或者买错了怎么办？**
A：激活失败全额退款；买错版本可以联系补差价换版本。具体的开通细节，购买后会有专属指引，一步步跟着做就行。
